# Online Resource

This directory contains material moved out of the manuscript to keep the article concise while retaining a complete, reviewable record of the experimental operationalization.

- [Full prompt templates](prompts.md): verbatim zero-shot, one-shot, and few-shot templates, the common system message, and links to the five executable generation notebooks.
- [Methodological details](methodological-details.md): metric implementation signatures, operational equations, statistical aggregation equations, and the full convergence derivation.
- [Secondary tables](secondary-tables.md): detailed methodological and inferential tables referenced in the manuscript but not required in its main narrative.

The root [README](../README.md) describes the complete replication-package structure. Executable notebooks and result artifacts remain in their task-specific directories.
