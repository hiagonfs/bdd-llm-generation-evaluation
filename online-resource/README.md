# Reproducibility materials

This directory documents the prompts, metric operationalizations, convergence procedure, and detailed results needed to inspect and reproduce the study.

- [Full prompt templates](prompts.md): exact zero-shot, one-shot, and few-shot templates, the common system message, and links to the five executable generation notebooks.
- [Methodological details](methodological-details.md): metric implementation signatures, operational equations, statistical aggregation equations, and the full convergence derivation.
- [Secondary tables](secondary-tables.md): detailed methodological and inferential tables supporting the reported analyses.

The root [README](../README.md) describes the complete reproducibility-package structure. Executable notebooks and result artifacts are organized in their task-specific directories.
